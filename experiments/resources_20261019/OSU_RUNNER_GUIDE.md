# OSU comparison runner

This experimental runner is prepared locally, not yet accepted on the ARM nodes. Eight local tests and a dry-run passed. No core HUCX/HMPI change. Uses pinned node-built OSU 7.5.2 hashes. Requires Python3, ssh, timeout and current MPI on both nodes; no optional GPU/PAPI libraries. Launch only on node89.

Default is plan-only. Add --execute to run. Required paths: --stage existing writable case directory, --runtime hucx_rm_repo_rebuild_20261019, --install osu_build_7.5.2_20261020_AOlmOB/install. Preserve archive/source/build from OSU_VALIDATION.md. MPI runtime core hashes should be verified against runtime_15c7293_BINARY_SHA256SUMS before the window; OSU six pinned hashes are checked as each phase uses them.

Phases: gate (64-byte latency); pt2pt (1 byte to 8 MiB powers of two, latency and bw); collective (4 bytes to 1 MiB powers of two, allreduce/bcast/gatherv/alltoall). Defaults: ppn1, binding core, repeats3, warmup20, iterations100, window64, timeout180 sec per run. Point-to-point requires ppn1. Collective supports ppn1/2/4, total2/4/8 ranks on two physical nodes. No oversubscription. A timeout stops progression; recorded failures must not be converted to latency numbers or discarded.

Run gate first during the reserved idle window with core binding, then validation gate (--validate --repeats 1), then chosen short correctness checks before broader performance runs. If core binding again fails, investigate; an unbound successful run is not a fix. Smaller iteration counts can be used for smoke tests but must be labelled. --validate adds -c -u 5 and is separate from performance runs. Log level warn; RM diagnostics, trace and injections disabled; observer LD_PRELOAD removed. Inherited UCX and OMPI_MCA variables cleared; explicit pml ucx / pml_ucx_tls any / pml_ucx_devices any, disables hcoll/ucc collective components to avoid external offload bypassing the intended PML. Both modes use identical MPI collective configuration, but internal algorithms can still depend on message/rank count. UCX protocol v1, auto rendezvous threshold; depth1024_priority5, TX256 and RC/UM TX JFC256. Path confirmation is a separate diagnostic run, not inferred solely from byte size.

plan.json records args, all commands and explicit exported environment. local/remote preflight records uptime/vmstat/process-name counts (no process arguments). The preflight is evidence, not an automatic idle guarantee or scheduler reservation. It does not prove network/device isolation or NUMA locality. Coordinate the idle window. No global kills, affinity changes to other jobs or device resets.

summary.json includes each completed run exit code, parsed size rows and unit. A PASS means exit0 plus valid OSU version/header/finite values and full expected size grid; validation Pass required only with --validate. It is not a performance target or assertion of advantage. OSU reports pt2pt latency as half round-trip average; do not label as clock-synchronized one-way measurement. Bandwidth unit remains MB/s as OSU prints. Collective sizes have benchmark-specific meaning; alltoall traffic is not equal to one message-size per rank. Local tests are fixture/parser/plan tests, no local MPI acceptance.

All raw outputs remain on nodes; publish bounded structured results and exact settings. Graphs should show repeat dispersion and failures separately, no cherry-picked minima. Memory results come from independent memory sampler, not this runner. Full command contains local infrastructure paths; do not upload bulk raw logs.
